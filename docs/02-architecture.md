# Architecture

## Philosophy

MNIP Test Automation is an onboarding framework, not a simple reset tool.

## Workflow

Device Connected
-> Discovery
-> Identification
-> Workflow Selection
-> Execution
-> Validation
-> Reporting

## Layers

### Discovery Layer

- Static port mapping
- LLDP discovery
- Future switch integrations

### Automation Layer

- Factory reset
- Provisioning
- Configuration deployment

### Validation Layer

- ST2110 verification
- Receiver validation
- Health checks

### Reporting Layer

- Logs
- Results
- Historical records
